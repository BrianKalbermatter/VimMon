# Mazmorra ASCII — arte para copiar y pegar

Arte para las 8 habitaciones de `dungeon.c` (`MAX_ROOMS 8`, indices 0..7).
Pensado para el grafo de habitaciones que ya tenes: `norte/sur/este/oeste`
como indices, `-1` cuando no hay salida.

`======` y `|` son las conexiones. Nada mas.

## Tabla de salidas

Los valores ya son reciprocos (si 0 va al este hacia 1, 1 va al oeste hacia 0).
Copiala tal cual a `init_rooms()`:

| # | Habitacion | norte | sur | este | oeste |
|---|------------|-------|-----|------|-------|
| 0 | Entrada    | 3     | -1  | 1    | -1    |
| 1 | Pasillo    | 4     | -1  | 2    | 0     |
| 2 | Armeria    | 5     | 7   | -1   | 1     |
| 3 | Biblioteca | -1    | 0   | 4    | -1    |
| 4 | Guardia    | 6     | 1   | 5    | 3     |
| 5 | Forja      | -1    | 2   | -1   | 4     |
| 6 | Trono      | -1    | 4   | -1   | -1    |
| 7 | Cripta     | 2     | -1  | -1   | -1    |

Tu `move_player(int direction)` usa `0=Norte, 1=Sur, 2=Este, 3=Oeste`, en ese
orden.

## Como meter esto en C

El arte tiene `\` y `|`. En un string de C, cada `\` del dibujo se escribe
`\\`, y cada `%` se escribe `%%`. Si no lo haces, el compilador interpreta
`\_` como una secuencia de escape invalida y el dibujo sale roto.

Concatenacion de literales adyacentes, una linea por linea del dibujo:

```c
static const char *ROOM0_ART =
    "+----------------------------------------+\n"
    "|             _|_|      |_|_             |\n"
    "|            |   |      |   |            |\n"
    "+----------------------------------------+\n";
```

Para imprimirlo:

```c
fputs(ROOM0_ART, stdout);        // bien
printf("%s", ROOM0_ART);         // tambien bien
printf(ROOM0_ART);               // MAL - ver abajo
```

`printf(ROOM0_ART)` trata el dibujo como formato. Un `%` suelto en el arte hace
que `printf` lea argumentos que nunca pasaste, y ahi tenes basura o un
segfault. Es la vulnerabilidad clasica de format string. Usa siempre `fputs` o
`printf("%s", ...)`.
