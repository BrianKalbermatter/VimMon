PAED - Documentacion del Compilador/Interprete
================================================
Lenguaje: .paed (pseudo + aed)
Herramienta: paed (script bash sin extension, ejecutable)

Que es paed?
------------
Es un interprete con fase de analisis previa.
Primero analiza TODO el archivo buscando errores de sintaxis.
Solo si no hay errores, ejecuta el codigo.
Esto lo diferencia de un interprete comun (como python) que explota en runtime.

Dos fases:
  1. analizar()  - recorre el archivo completo, valida estructura
  2. ejecutar()  - solo corre si analizar() no dio errores (return 0)

- Creado tests/hola_mundo.paed (primer archivo de prueba)

- paed tiene:
    - Verificacion de argumento vacio         ([ -z ])
    - Verificacion de archivo existente       ([ ! -f ])
    - Verificacion de extension .paed         (${ARCHIVO##*.})
    - while read linea con case para detectar palabras clave:
        ACCION*ES, FIN_ACCION, AMBIENTE, PROCESO

- Conceptos bash aprendidos hoy:
    $1             primer argumento del script
    [ -z ]         verifica si variable esta vacia
    [ ! -f ]       verifica si archivo NO existe
    ${VAR##*.}     extrae extension del nombre de archivo
    return 1       devuelve error y para la funcion
    $?             codigo de salida del ultimo comando
    while read     leer archivo linea por linea
    case/esac      comparar variable contra patrones
    PATRON*)       el * matchea cualquier cosa despues
