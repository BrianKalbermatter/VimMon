# examRHCSA - Guia completa de estudio

Guia de ejercicios practicos para preparar el RHCSA combinando Bash, C y administracion de sistemas Linux.

## Estructura

```
examRHCSA/
├── fase1_bases_linux/        # Semanas 1-3
├── fase2_bash_scripting/     # Semanas 4-7
├── fase3_rhcsa_sysadmin/     # Semanas 8-14
├── fase4_c_sistemas/         # Semanas 15-20
├── fase5_integracion/        # Semanas 21+
```

## Ruta de estudio

| Fase | Tema                  | Duracion   |
|------|-----------------------|------------|
| 1    | Bases Linux           | 3 semanas  |
| 2    | Bash scripting        | 4 semanas  |
| 3    | RHCSA / Sysadmin      | 7 semanas  |
| 4    | C para sistemas       | 6 semanas  |
| 5    | Integracion + examen  | continuo   |

## Recursos

- RHEL 9 gratis: https://developers.redhat.com
- Documentacion oficial: https://docs.redhat.com
- Alternativas gratuitas: Rocky Linux 9, AlmaLinux 9

## Nota importante

El examen RHCSA actual es sobre RHEL 9.
Practica todo en la terminal, no solo leas.
